# PRODUCT.md

## Platform
web

## Stack
TypeScript run natively by Node 24 (type stripping, no build step). Zero runtime dependencies. Self-contained HTML report generated by `src/report/build.ts` with inline SVG charts. Local model inference via Ollama; hosted providers via fetch. The case-study surface is a single standalone HTML file, no framework, no network dependencies.

## Product Purpose
A partner bench: it scores every AI lab a deployment company is partnered with, per workload, on the dimensions that decide whether a deployment makes money — calibration, cost per resolved unit, schema adherence under mess, p95 latency, refusal rate, degradation on Indian-context input, and silent model-version drift. It then stops ranking models and starts composing them, and includes a no-model baseline so the first question can be *does this need a lab at all*.

The case-study surface exists to carry the reasoning, the system, and the findings to a reader who will not open a repository.

## Positioning
Not a leaderboard. A leaderboard ranks models; this prices deployments. Public benchmarks measure nothing an FDE company sells.

Commercially it converts partnerships from asking into trading: not "we'd love credits" but "here is your model's measured position on our workloads, and here is what we'd need to see to route more volume to you."

## Capabilities and Constraints
- Runs with no API keys against a mock provider that stamps every output non-evidential; live and mock can never share a grid.
- Three workloads, all generated at run time from a documented corruption model: Indian address → serviceability, OCR'd invoice → line items, Hinglish support ticket → routing.
- 40 unit tests, several checked against textbook values (Wilson 10/10 → 0.7225; McNemar b=10 c=2 → p=0.03857).
- Real run executed on three local models via Ollama at ₹0.
- **Constraint that must survive to the page:** the gazetteer baseline holds the same PIN directory the eval items were generated from. Realistic, but it is a lookup measured against models given no reference data. The caveat travels with the number, always.
- Eval sets are synthetic; n is small; ground truth is asserted, not audited; model prices in `data/pricing.json` are unverified placeholders.

## Evidence on Hand
Real, measured, reproducible:
- Address workload, n=400, three columns: **Gazetteer (no model) 94.8% accuracy, 92% automatable, 0.00% escaped errors, ₹25,836/month against ₹2.98 lakh manual — a 91% saving.** qwen2.5 7b 60.5% and qwen3 8b 49.8%, neither able to automate anything inside a 2% error budget.
- Paired McNemar, Holm-corrected: both gazetteer gaps real at p<0.001. At n=60 the model-vs-model gap read noise (floor 24.4pt); at n=400 it reads real (floor 4.4pt) — same models, sample size was the whole difference.
- qwen2.5:14b disqualified on measured latency: 72.8s per invoice at 6 tok/s, ≈2,028 GPU-hours per month at 100k invoices.
- `BLINDSPOTS.md`: twenty ways an evaluation bench lies, each mapped to the file that handles it, and **eight defects this code was caught committing** — three of which only surfaced when mock providers were replaced by real ones, and three of which all pointed toward the conclusion the bench was built to argue for.
- 4,889 lines of TypeScript, 408 of tests, zero dependencies, ₹0 spent.

## Product Principles
- Nothing is shown without its uncertainty.
- A number the sample cannot support is reported as unmeasured, never as absent.
- No part of the analysis chooses its own evaluation set.
- Refusals, repairs and version drift are recorded, never smoothed away.
- The harness is the artefact; the numbers are a demonstration.

## Accessibility & Inclusion
Body text at 4.5:1 minimum against bone paper. Ink rules and Klein blue carry structure, never colour alone: every state also carries a label or a shape. Charts are inline SVG with titles and text labels, readable without colour discrimination. Responsive from 360px; wide tables scroll inside their own container so the page body never scrolls horizontally. Respects `prefers-reduced-motion`; nothing is hidden until script confirms it can reveal it.
